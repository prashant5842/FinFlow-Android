## Install

1. Download the APK to your Android device.
2. Open it and follow Android's install prompts. If asked, allow your browser or file manager to install apps from this source.
3. FinFlow is distributed outside Google Play. Install it only if you trust this publisher.

FinFlow requires Google sign-in for account sync. See the [privacy policy](https://finflow-c307f.web.app/privacy) and [terms of service](https://finflow-c307f.web.app/terms).
